一群光标，把这一页
重新盖出来

swarm-builder 采集页面 DOM，拆成矩形、文字、媒体、重复模块与辅助线， 再交给多个光标按你选的顺序施工；盖完收工，真实页面交还给你。 你现在看到的这一页，就是它重建的。

它拆出什么，就盖回什么

矩形与骨架

每个盒子带尺寸徽章落位，边框、圆角、底色按采集那一帧还原，容器先把骨架撑起来。

逐字打字

文本逐字符写出，I 型光标与插入符跟着走；大标题可以一边打字一边长到真实字号。

媒体与降级

img、svg、canvas/video 截帧都会真的呈现；取不到的资源降级成占位框，不会留一个洞。

重复模块盖章

一列相似的兄弟只真做一个，其余按住 ⌥ 拖过去盖章，列表和卡片墙不必一行行重打。

辅助线与吸附

布局本来就有的对齐线先画出来，盒子落位时吸上去，收尾再淡出。

多光标集群

1–24 个光标同场施工，队列分发可选七套顺序，还能开工时均衡让它们差不多同时收工。

怎么用

  1. 1

    装它

    零依赖，一个包三种格式；CDN 直接引 IIFE 也行。

    npm i swarm-builder
  2. 2

    指一个容器

    root 给谁就重建谁，页面其余部分不受影响；mount() 是最小写法。

    import { mount } from 'swarm-builder';

mount({
  root: document.querySelector('#app'),
  agentCount: 8,
  order: 'rows',   // 自上而下
  tour: true,      // 镜头跟着施工前沿
  sound: true,
});
  3. 3

    改到满意，再抄配置

    创造者模式挂在页面上，18 项参数一屏全露；调好后一键导出可以直接粘进代码的片段。

    import { tune } from 'swarm-builder/tune';

tune({ root: '#app', initial: { order: 'depth', balance: true } });

参数速查

完整清单见 README；这里挑最常动的几项。全部都能在创造者模式里改。

参数取值它在管什么
agentCount1–24同时施工的光标数，越多越快也越吵
ordergroup / rows / cols / snake / depth / radial / random光标怎么认领这一页；竖列在没有真沟时自动退回横带
balance布尔把带切成等预估工时而不是等件数，避免一个光标收尾其他人干等
seed数字，0 = 现抽随机顺序的种子，完成状态会回显实际用的那颗
speed / targetDuration0.25–8 / 秒倍率，或交给估算器反推倍率把整场压进固定时长
tour布尔滚动跟着施工前沿走，结束交还页首
sound布尔合成音效，不用带音频文件
maxItems / ignore数字 / 选择器蓝图上限；命中的子树整块跳过
theme / performanceModeauto 优先施工线墨色按页面明暗；拥挤页面自动裁剪特效

用之前知道的几件事

  • 它是进场动画，不是懒加载：动画定格在采集那一瞬间，重建出来的盒子没有交互。
  • 页面很长先看 maxItems，超出的条目计入 dropped 而不是被盖出来。
  • 伪元素、跨域 canvas、Web Component 的 shadow DOM 会降级成占位框——有占位，不留空洞。
  • 浏览器要求页面已有用户手势才发声，所以自动开局的那一次可能静音，点一下就回来了。
  • 用户偏好减少动效时请自己判断再开局：matchMedia('(prefers-reduced-motion: reduce)')。
