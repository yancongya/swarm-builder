01

它拆出什么，就盖回什么

从外框到文字、媒体、重复模块与对齐线，采集到什么就照原样盖回去，盒子位置一像素不挪。

RECT

矩形与骨架

盒子带着尺寸徽章落位，边框、圆角、底色照采集那一帧还原；容器先把骨架撑起来。

TEXT

逐字打字

文本一个字符一个字符敲出来，I 型光标与插入符跟着走；大标题能边打字边长到真实字号。

MEDIA

媒体与降级

img、svg、canvas/video 截帧都会真的呈现；采集前先把整页滚一遍把懒加载逼出来，取不到的才降级成占位框。

CLONE

重复模块盖章

一列相似的兄弟只真做一个，其余按住 ⌥ 拖过去盖章；卡片墙不必一行行重打。

GUIDE

辅助线与吸附

布局本来就有的对齐线先画出来，盒子落位时吸上去，收尾再淡出。

SWARM

多光标集群

1–24 个光标同场施工，七套认领顺序；默认 8 个起，随滚动与积压自动增减到 48。想让大家差不多同时收工，就打开工时均衡。

02

+

库这头多出来的

  • 给秒数定速收尾，七套认领顺序任选；原版只有一套固定顺序。
  • 只盖首屏或单个子树，结束后真实 DOM 原样交还；参数一键导出成代码。
−

库这头不如原版的

  • 盖不了别人家的页面，也跨不了页：取不回 HTML 就原样显示。
  • 只是进场动画：盒子不带交互，原版更新了也不会自动跟。
03

怎么接

三步：装包、指一个容器、调好再抄配置。每一步都能在一页 HTML 里完成。

  1. 1

    装它

    零依赖，一个包三种格式。还没上架 npm：克隆后构建一次再本地安装；发版后换成 npm i swarm-builder，CDN 也能直接用。

    git clone https://github.com/yancongya/swarm-builder.git
cd swarm-builder && npm install && npm run build

# then, in your project:
npm i ../swarm-builder
# or: npm pack && npm i ./swarm-builder-0.1.0.tgz
  2. 2

    指一个容器

    root 给谁就重建谁，页面其余部分照常跑；不传其余参数，落地就是原版那套：自上而下、镜头跟随、声音全开。

    import { mount } from 'swarm-builder';

mount({
  root: document.querySelector('#app'),
  agentCount: 8,
  order: 'rows',   // 自上而下
  tour: true,      // 镜头跟着施工前沿
  sound: true,
});
  3. 3

    改到满意，再抄配置

    创造者模式挂在页面上，29 项参数按用途分成六页，一次只摊开一页；调好一键导出，那份片段可以直接粘进代码。

    import { tune } from 'swarm-builder/tune';

tune({ root: '#app', initial: { order: 'depth', balance: true } });
给 AI 的提示词 把下面这段原样粘给 coding agent，它能在你自己的项目里接完 
用 swarm-builder 在我的项目里做「一群光标把页面重建出来」的进场动画。它是零依赖的 MIT 库，ESM / CJS / IIFE 三种格式都有。

1. 装：npm i swarm-builder；还没上架时先 git clone https://github.com/yancongya/swarm-builder.git，npm install && npm run build，再在项目里 npm i 本地路径或用 npm pack 出的 tgz。走 CDN 就引 dist/swarm-builder.iife.js，全局名 SwarmBuilder。框架里等容器挂载完再开局（React 用 useEffect、Vue 用 onMounted），部署就是把这几个文件当静态资源发出去，没有服务端。
2. 指一个容器来重建，页面其余部分不动：
   import { mount } from 'swarm-builder';
   mount({ root: document.querySelector('#app'), agentCount: 8, order: 'rows', tour: true, sound: true });
3. 要边看边调就换成创造者模式（右下角悬浮球，29 项参数按用途分六页：规模 / 顺序 / 光标 / 采集 / 声音 / 外观。一次只摊开一页，页签悬停能看到这一页的当前值，改完点「应用并重跑」）：
   import { tune } from 'swarm-builder/tune';
   tune({ root: '#app', initial: { order: 'depth', balance: true } });
4. 常规参数：agentCount 1–24 个光标；order 取 group / rows / cols / snake / depth / radial / random；balance 按预估工时均衡各队列；speed 是 0.25–8 倍率，targetDuration 给秒数让估算器反推倍率；seed 固定即可重放（0 = 每局现抽）；maxItems 是蓝图上限，超出计入 dropped；ignore 用选择器跳过整棵子树；duplicate / maxCopies 管重复模块盖章；guides / maxGuides 管辅助线；grow 是标题字号步进；flocking 让光标互相避让；tour 让镜头跟随施工前沿；sound 是合成音效；theme 是施工线墨色；performanceMode 在密集页面自动裁剪特效。
5. 下面十一个开关默认就按原版那一套打开，关掉才退回朴素模式：flight（live 待时绕圆心飞 / idle 停在落点），pointer（follow 鼠标当圆心 / ignore / repel 48px 排斥环，只在 live 下有用），agents（auto 人数随滚动速度与积压活增减，上限 48 / fixed 固定），gather（开局先聚 18 只再散开 / 直接开工），pick（live 每帧给所有活定价谁近谁抢 / queued 按预切队列），trigger（scroll 只放行滚过的部分 / immediate 第一帧全放），adaptiveSpeed（积压每件 +45% 最多 4 倍），scan（pre-scroll 先把整页滚一遍等懒加载和图片，重建别人的站点要用这档 / single 走一遍），score（generative 104 BPM 生成式配乐 / off 只有点击声），reducedMotion（skip 一项不建直接交还 / run 照跑），keys（Esc 收工、M 静音，输入框留给宿主 / 关掉不碰键盘）。
6. 别做的事：不要为了动画改我的页面结构；这是进场动画，重建出来的盒子没有交互，结束后真实 DOM 原样交还。
7. 验收：跑完 console 无报错、文档宽度不超出视口、动画结束后原页面照常可交互。
04

参数速查

29 项按用途分六页，和面板一一对应；完整签名在 README，这里给的是最常动的那一面。

规模

施工规模

几个光标、建多少、多快。

agentCount1–24同时施工的光标数，越多越快，画面也越吵
agentsauto / fixedauto 时人数是下限、48 是上限，按滚动速度与积压活增减
maxItems数字蓝图上限，超出的计入 dropped
speed0.25–8×基础倍率；开了积压提速后它变成下限
targetDuration秒，0 = 关交给估算器反推倍率，把整场压进固定时长
performanceModeauto / high / lowauto 超过 250 个盒子就裁剪辅助线与标题步进
顺序

认领与顺序

活怎么分、按什么顺序放行。

order7 套光标怎么认领这一页；竖列在没有真沟时自动退回横带
balance布尔按预估工时切等分而不是件数，避免别人干等一个收尾
seed数字，0 = 现抽随机顺序的种子，完成状态会回显实际用的那颗
pickqueued / live REF守着切好的队列，还是每帧定价、谁近谁抢
triggerscroll / immediate REF只放行滚过的部分，还是第一帧全放行
gather布尔 REF开局先聚群，一滚或一碰就散开，最多绕 2.4 秒
adaptiveSpeed布尔 REF积压每件 +45%、最多 4 倍；speed 与 targetDuration 变成下限
光标

光标行为

没活时怎么飞、鼠标算不算、镜头跟不跟。

flightlive / idle REF干完活回群里绕轨道飞，还是停在落点
pointerfollow / repel / ignore REF鼠标当圆心、48px 排斥环，或干脆不理
flocking布尔光标在途中互相避让
tour布尔滚动跟着施工前沿走，结束交还页首
keys布尔 REFEsc 收工、M 静音；输入框留给宿主
采集

采集与内容

蓝图采哪里、复制、辅助线与跳过。

scanpre-scroll / single REF先滚一遍等懒加载和图片，还是走一遍 DOM 就开建
duplicate布尔重复兄弟只真做一个，其余拖拽盖章
maxCopies1–48每组重复最多盖几个
guides布尔画出布局本来就有的对齐线
maxGuides0–64一次运行最多画几条
grow布尔大标题边打字边长到真实字号
ignore选择器逗号分隔，命中的子树整块跳过
声音

声音与配乐

合成音效与配乐。

sound布尔合成音效，不用带音频文件
scoregenerative / off REF104 BPM 生成式配乐，还是只有点击声
外观

外观与可访问性

减少动效与施工线墨色。

reducedMotionskip / run REF系统要省动效就不建直接交还，还是照跑
themeauto / light / dark施工线墨色按页面明暗，或手动指定

带 REF 的十一项是原版开关，默认全开；关掉任一项再点「应用并重跑」就退回朴素模式。

05

用之前知道的几件事

它擅长的是「把已经存在的一页盖出来」，下面几条是它的边界，不是待修的 bug。

  • 它是进场动画，不是懒加载：画面定格在采集那一瞬间，重建出来的盒子没有交互。
  • 页面很长先看 maxItems，超出的条目计入 dropped 而不是被盖出来。
  • 伪元素、跨域 canvas、Web Component 的 shadow DOM 会降级成占位框——有占位，不留空洞。
  • 浏览器要求页面已有用户手势才发声，所以自动开局的那一次可能静音，点一下就回来了。
  • 系统要求减少动效时怎么走由 reducedMotion 定：默认 'skip' 一项不建、直接把真实页面交还；'run' 才照跑（这是宿主主动要的装饰）。
  • 预览壳里输入第三方地址，取得到 HTML 才会重建：同源页面与本地预览的同源转发可以，公网站点多半被 CORS 挡住，那就只原样显示。

效果基准来自原版 Swarm Rebuild，本项目按公开可观察的行为重新实现， 没有复制任何第三方源码。源码、Issue 与发行说明在 yancongya/swarm-builder ，MIT 许可。
