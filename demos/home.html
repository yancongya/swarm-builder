02 / QUICK START

接入你的页面，
让它开工。

指定一个容器，Swarm Builder 只处理这块区域。动画结束后，原来的 DOM 和交互继续工作。

想边看边调？右下角的创造者模式可调整光标数量、构建顺序、速度、声音与镜头跟随。

03 / BEFORE YOU BUILD

页面是你的。
进场交给我们。

这是进场动画。施工中的临时盒子用于呈现构建过程，不承载业务交互；结束后才显示真实页面。

你可以重播，也可以打开右下角悬浮窗口，现场调整参数后重新构建。

交给 AI 接入

请为我的项目接入 Swarm Builder 的网页进场动画。请按下面的步骤实际执行，不要只给安装建议。

1. 下载并构建源码（当前 npm 尚未发布，仓库不提交 dist，请不要直接运行 npm i swarm-builder 或 npm i github:yancongya/swarm-builder）：
   git clone https://github.com/yancongya/swarm-builder.git
   cd swarm-builder
   npm install
   npm run build
2. 回到我的项目目录，从本地构建好的仓库安装：
   npm i ../swarm-builder
   如果目录不相邻，请改成 swarm-builder 仓库的实际路径。也可以在仓库运行 npm pack，再在我的项目安装生成的 swarm-builder-0.1.0.tgz。
3. 等我的目标容器挂载后接入：
   import { mount } from 'swarm-builder';
   mount({ root: document.querySelector('#app'), agentCount: 8, order: 'rows', tour: true });
   把 #app 换成我的真实容器；React 用 useEffect，Vue 用 onMounted。
4. 保持现有页面结构与业务逻辑。动画只是进场效果，临时构建盒子不可交互；结束后真实 DOM 应原样交还。请在手机视口检查没有横向溢出，并验证原页面交互正常。
